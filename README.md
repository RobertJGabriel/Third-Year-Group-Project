# Third-Year-Group-Project

![Gym booking system](.github/readme.png "Gym booking and content management system")

> A gym booking and content management system in PHP.

Members book training sessions and log the results of each one. Staff manage
content and bookings through an admin area. Built as a third-year group project.

## Requirements

- PHP with a web server — Apache via XAMPP or MAMP is easiest
- MySQL

## Setup

1. Create a database and import the SQL script included in the repository.
2. Update the database credentials in the config file.
3. Serve the project root and open it in a browser.
